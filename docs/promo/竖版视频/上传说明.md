# 竖版推广视频（2026-11-09）

三条视频都是 1080×1920 的 MP4（H.264 + AAC 配乐），时长 23~24 秒，大小 14~29 MB。画面全是实机录制，没有后期加的文字和特效。

第二版（用户要求）：带真实的战斗界面，包括等级、斩敌、计时、兵器栏、大招、金疮药、连斩、名将大招立绘切入，全程是真实的滑动摇杆操作。升级、锦囊这类选择弹窗不录。
每条视频配一张实机帧封面（1080×1920 JPG，小于 500 KB）。三条分别取自 0.20 秒、7.78 秒、2.94 秒；裁取战斗区域，隐去角色脚下的血条，底部使用游戏首页的「长坂单骑传」字标和朱印。

重新生成视频和封面：先运行 `npm run build` 和 `node tools/video/record6.mjs`，再运行 `python3 tools/video/compose6.py`。
- 只重做封面：在仓库根目录运行 `node tools/video/vertical-covers.mjs`，使用 FFmpeg 从已生成的三条 MP4 导出 JPG。
- 只重做视频：合成前设置 `VIDEO_ONLY=1`。视频保留真实战斗界面与摇杆，和封面分别生成。
