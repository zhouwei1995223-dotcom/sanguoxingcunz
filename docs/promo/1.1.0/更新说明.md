# 1.1.0 更新说明（画面全面翻新 + 三十名将）

> 1.0.8 如果还没提审，把 `docs/promo/1.0.8/更新说明.md` 里的天机签等条目一起写进本次「更新内容」。

## 一、上传时的「版本描述」
1.1.0：界面与主城画面全面翻新；新增二十位武将（共三十位）；主界面精简为征战与天机签，新增「演武」页

## 二、提审时的「更新内容」
1. 画面翻新：主城换成青绿山水长卷（远山、落日、流云、归雁、桃花），全部界面换成「鎏金水墨」风格——描金漆面按钮、宣纸卷轴面板、墨漆导航栏
2. 新增二十位武将，共三十位，分蜀、魏、吴、群四个阵营：刘备、魏延、曹操、夏侯惇、张辽、许褚、司马懿、夏侯渊、甄姬、孙策、周瑜、甘宁、太史慈、陆逊、小乔、貂蝉、董卓、张角、华佗、左慈。每位都有专属兵器、专属大招、天赋、两条专属联动、觉醒造型和皮肤
3. 武将页重做：名册按阵营筛选，点开看详情；新增「心愿武将」——随机碎片有 45% 归心愿武将
4. 主界面只保留「征战」「天机签」；守城、布阵、无尽、每周挑战收进底部新页签「演武」
5. 启动页、提示条、弹窗、战斗界面同步换新

更新提醒词库标签：推出新角色、推出新功能、优化游戏体验

## 三、版本更新信息（15 字以内）
- `三十名将齐聚，画面全新`（11 字）
- `新增二十武将，界面翻新`（11 字）

## 四、概率公示（已在游戏内「商店 → 概率公示」同步）
- 武将碎片的归属：三十位武将按品阶给权重（名将宝匣偏向无双 / 名将，军资箱偏向良将）。
- 心愿武将：每次随机获得武将碎片时，45% 概率为心愿武将的碎片，其余 55% 按各宝箱的归属概率抽取。没有手动指定时，自动选「还没解锁、离解锁最近」的一位；全部解锁后自动选出战武将。
- 名将宝匣 5% 直接得武将、15 次保底的规则不变（优先从尚未拥有的武将里等概率抽）。

## 五、广告与 We分析
- 没有新增广告点位。新武将皮肤沿用 `skin_<武将id>`（`ad_reward` 的 `placement` 会多出二十个取值，例如 `skin_caocao`）。
- `battle_start` / `battle_end` 的 `hero` 新增二十个取值（新武将 id）。

## 六、小红书版
版本号与微信一致（1.1.0），内容相同、没有广告。关注送孙尚香、评论 / 笔记奖励、天机签排行榜都保留。上传时仍要勾选「用户头像昵称授权」。

## 七、真机上请重点看
1. 主城和各页签滑动是否流畅（新界面的按钮、面板都缓存成贴图，理论上比旧版省）；
2. 安卓微信上文字是否清晰（标题、导航栏）；
3. 新武将的大招：张辽「威震逍遥津」会连续闪到敌人身边，左慈「奇门遁甲」会把敌人吸过来——手感是否合适；
4. 老存档读档后二十位新武将都是「未获得」，碎片为 0，其他进度不变。
