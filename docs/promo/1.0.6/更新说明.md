# 1.0.6 更新说明

## 一、上传时的「版本描述」
1.0.6：新增守城模式、武将巅峰等级、五星觉醒造型；更新提醒补充基础库版本判断

## 二、提审时的「更新内容」
1. 新玩法「守城」：主界面切换到「守城」页签，十座名城依次挑战。城池在地图中央，敌军四面攻城，召唤枪兵、盾兵、弓兵、骑兵、弩车和已解锁的武将一起守城，升级时还能选择城防军令和兵种联动
2. 武将大招特效全面升级：大招立绘切入、冲击波、光柱、流星等华丽演出
3. 武将五星后可继续提升「巅峰等级」，多余的碎片不再浪费
4. 武将五星解锁「觉醒」步战造型，形象更华丽，并获得额外属性
5. 修复部分机型「更新提醒」报错的问题

更新提醒词库标签：推出新玩法、推出新功能、新皮肤上线

## 三、版本更新信息（15 字以内，显示在「发现-小程序」等入口）
- `新玩法守城上线，召兵守城`（12 字）
- `守城模式上线，四面御敌`（11 字）
