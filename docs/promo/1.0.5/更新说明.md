# 1.0.5 更新说明

## 一、上传时的「版本描述」
1.0.5：修复主界面「推荐」「更新提醒」点击没反应；增加启动来源统计

## 二、提审时的「更新内容」
1. 修复主界面「推荐」「更新提醒」按钮点击没有反应的问题
2. 修复结算页「推荐给好友」按钮有时打不开的问题
3. 优化稳定性

更新提醒词库标签：修复bug、优化性能

## 三、We分析要补的配置（数据管理 → 上报管理 → 元事件）
- 新属性 `src`（字符型）：玩家第一次进游戏的来源。`ad` = 从腾讯广告点进来；`s1001` 这类 = 微信场景值（1001 发现栏小程序主入口、1089 下拉最近使用、1037/1038 从别的小程序跳转等）；`old` = 1.0.5 之前就装了的老玩家。
- 给 `login`、`ad_reward` 两个事件补上 `src` 属性。
- `recommend` 事件的 `ok` 新增取值 -2：推荐组件打开失败（同时会提示错误信息）。
