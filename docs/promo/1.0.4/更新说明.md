# 1.0.4 更新说明

## 上传时的「版本描述」（开发者工具上传备注）
1.0.4：一局6分钟、敌将加强、三星评价、复活与广告奖励调整、评价推荐、更新提醒、客服入口

## 提审时的「更新内容」
1. 一局缩短为6分钟：第3分钟、第6分钟各迎战一名敌将，节奏更紧凑
2. 敌将加强：不再被秒杀，血量降到三成后进入二阶段，招式更快更猛
3. 新增三星评价：通关、不复活、80秒内击败最终敌将，集齐三星领元宝
4. 击败中途敌将后出现「直取敌将」，每局一次，可直接挑战最终敌将
5. 复活奖励：第二、三次复活获得本局伤害与移速加成
6. 商店补给、体力、快速巡营的视频奖励一次比一次多
7. 无尽模式节奏加快，每3分钟结算一次奖励
8. 新增「推荐给好友」「更新提醒」，设置中新增「联系客服 / 反馈」

## 游戏更新提醒的词库标签（提交审核页最多选 3 个）
推出新玩法、推出新功能、优化性能
（发布全量后 24 小时内，平台自动给订阅了「更新提醒」或加入游戏圈的玩家发服务通知）

## 发布后要做的
- We分析「上报管理」：给 `battle_end` 加属性 `boss_sec`、`revives`（整数），给 `ad_reward` 加属性 `idx`（整数）；新事件 `recommend`（from 字符、ok 整数）、`update_notice`（ok 整数）、`service`（from 字符）出现在「未定义事件」后再定义。
- 游戏圈发一条更新帖（可用下面这段）。
