## 帖子 2

**标题：** 新手必看｜5 个小技巧，第一局就能多撑几分钟

**正文：**

刚进游戏的朋友看这里👇

1️⃣ **只管走位，不用点攻击**
武器都是自动攻击的，手指拖动只负责走位。别站着不动，绕着敌人兜圈子，边走边打最安全。

2️⃣ **升级三选一，先把一把武器升满**
武器升满 5 级、并且学过对应的兵法，打开敌将宝箱就能**进化**，伤害直接翻好几倍。别每样都拿一点，集中升一两把。

3️⃣ **金疮药别省着**
大招旁边的「金疮药」能回 25% 血，冷却 45 秒。血掉到一半就可以喝，冷却好了再喝一口。

4️⃣ **锦囊认真选**
2:00、5:00、7:30 各开一次锦囊，三选一。打不过就选回血、减伤的，稳了再选加伤害的。

5️⃣ **怒气满了放大招**
左下角大招按钮转满就能放。被围住的时候放，直接清出一片空地。

打不过也没关系，回主城升级装备和军略，战力上去了再来，会轻松很多💪

## 帖子 3

**标题：** 武器进化表｜哪把武器配哪本兵法，一张帖子说清楚

**正文：**

进化条件：**武器满 5 级 + 身上有对应的兵法（1 级就行）**，然后打开敌将宝箱就会进化。

⚔️ 武将专属
· 龙胆枪（赵云）+ 虎符 → 百鸟朝凤
· 青龙偃月刀（关羽）+ 虎符 → 春秋刀法
· 丈八蛇矛（张飞）+ 铁甲 → 万人敌
· 羽扇（诸葛亮）+ 兵书 → 八阵图
· 方天画戟（吕布）+ 战马 → 无双乱舞

🗡️ 通用武器
· 青锋剑 + 令旗 → 万剑归宗
· 连弩 + 兵书 → 诸葛连弩
· 轻骑 + 战马 → 铁骑突阵
· 火油罐 + 漏刻 → 火烧连营
· 罡风 + 灵芝 → 金刚护体
· 回旋飞刀 + 鹰羽 → 飞刀如雨
· 天雷 + 玉玺 → 太平要术
· 滚木礌石 + 铁甲 → 天崩地裂
……后面章节还会解锁更多武器

💡 小提示：
· 战斗中点暂停 →「查看进化表」，随时能查
· 敌将宝箱有保底：满级武器缺兵法的话，宝箱会直接送这本兵法并当场进化

你最喜欢哪个进化？我投「火烧连营」一票🔥

## 帖子 4（等 1.0.2 发布上线后再发）

**标题：** 1.0.2 更新｜新手试炼、1.5 倍速、直取敌将来了

**正文：**

谢谢大家的反馈！这次更新的内容都来自玩家建议👇

🆕 **新功能**
· 新手试炼：第一次进游戏先打 1 分钟试炼，快速上手
· 1.5 倍速：战斗右上角可以切换

· 游戏圈入口：主界面侧边的「游戏圈」按钮，点一下就能进来

⚖️ **平衡调整**
· 金疮药冷却 60 秒 → 45 秒
· 小兵的弓箭伤害降低
· 敌将更强了，但敌将宝箱更值钱：没武器能进化时，也会直接帮你进化或送一大波升级

✨ **手感优化**
· 小兵出手前会闪白预警，有时间躲
· 连弩、天雷特效加强
· 暂停里可以关震动、关伤害数字
· 好友排行榜字体改小，更好看
· 继续降低手机发热

有什么想要的功能，评论区告诉我，下个版本见👋
