## 重新生成
1. `npm run build`
2. 截图：`SHOT_DIR=dist/promo2 Q='?skip=1&rich=1&heroes=1' node tools/shot.mjs promo2`（`ONLY=home,battle,tianji` 只拍其中几段；同时导出觉醒造型像素图到 `dist/promo2/sprites/`）
3. 图片：`python3 tools/promo/compose2.py <NotoSerifCJK-Black.ttc>`；头像：`node tools/shots/avatar3.mjs && python3 tools/promo/avatar3.py`
4. 视频：`node tools/video/record5.mjs && python3 tools/video/compose5.py <NotoSerifCJK-Black.ttc>`

字体：思源宋体 Noto Serif CJK Black（SIL OFL），下载地址 `https://github.com/notofonts/noto-cjk/raw/main/Serif/OTC/NotoSerifCJK-Black.ttc`；另需系统的文泉驿正黑、Pillow、ffmpeg。
