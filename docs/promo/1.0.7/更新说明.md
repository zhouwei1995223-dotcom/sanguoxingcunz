# 1.0.7 更新说明（微信版整体换成网页版）

> 如果 1.0.6 当时没有提审，把 `docs/promo/1.0.6/更新说明.md` 里的守城、巅峰等级、五星觉醒、营地主界面等条目一起写进本次「更新内容」。

## 一、上传时的「版本描述」
1.0.7：界面换成水墨宣纸风格；新增布阵玩法六关；守城、征战玩法与数值全面更新

## 二、提审时的「更新内容」
1. 全新水墨宣纸画风：主界面、弹窗、战斗按钮统一改为宣纸墨线风格，人物与营地像素画精绘
2. 新玩法「布阵」：六座关隘（柳营驿道、汉水双渡、剑阁夹道、虎牢关、赤壁、五丈原），每关 8～12 波进攻；建塔、援将、阵法三选一，塔与阵法可联动；城门失守可重振再战
3. 守城更新：武将阵亡即判负、可复活；敌将会攻击士兵；阵亡兵种按编制自动补员；召唤的武将属性随养成提升，释放技能有专属动画；城边建筑新增建造与攻击动画
4. 征战更新：对局可选 5 分钟或 10 分钟；三星评价、敌将预警与截击、武器与敌军数值重新调整；新增战报、备战技能预设、更多武器奇遇与锦囊
5. 每局最多复活三次，每次复活获得额外加成
6. 商店：两种宝箱每天可各看一次视频免费十连抽；成就与任务支持一键领取

更新提醒词库标签：推出新玩法、推出新功能、优化游戏体验

- `新玩法布阵上线，六关来战`（12 字）

## 四、广告与 We分析
- 新增的激励视频点位都共用现有广告位 `adunit-58a7793eb5931638`，只是 `ad_reward` 上报的 `placement` 取值不同，不用新建属性：
  `tower_speed`（布阵二倍速）、`tower_revive`（布阵复活）、`tower_aid`（援建）、`tower_repair`（修城门）、`tower_double`（结算双倍）、`chest_ten_wood` / `chest_ten_gold`（宝箱每日十连）、`revive`（征战 / 守城复活）。
- `battle_start` / `battle_end` 的 `mode` 新增取值 `tower`（布阵），`chapter` 为关卡号 1～6。

## 五、小红书版（`长坂单骑传-小红书v1.0.7.zip`）
内容与微信版一致，区别：没有广告，原来「看视频」的地方全部免费（二倍速、复活、宝箱十连、刷新等）；顶部为小红书的「··· / 关闭」按钮留了约 44 像素。已按官方 minitool-zip-builder 1.10.0 校验并通过审计（目录与最终 zip 均 PASS）；存档在客户端 9.46+ 改用小红书 Storage 并自动迁移旧进度，9.49+ 按顶部按钮实际位置避让，9.50+ 振动走平台接口。上传后先在创服平台模拟器完整验证，再用 Android、iOS 真机扫码验证。
