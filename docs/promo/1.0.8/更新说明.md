# 1.0.8 更新说明（新模式「天机签」）

> 如果 1.0.7 当时没有提审，把 `docs/promo/1.0.7/更新说明.md` 里的水墨画风、布阵六关等条目一起写进本次「更新内容」。

## 一、上传时的「版本描述」
1.0.8：新增天机签模式；加速改为 1.5 倍；备战一键推荐；加载与流畅度优化

## 二、提审时的「更新内容」
1. 新模式「天机签」：无名剑客独闯十分钟，砍树打怪攒金币摇签，六十余种随机签——名将兵器、借名将大招、宝箱雨、怪潮、夺兵、赌局……签签不同；8:30 天命之主登场，90 秒内的伤害计入排行榜
2. 加速统一改为 1.5 倍：征战免费开启，守城、无尽、每周挑战看一次视频开启
3. 备战新增「推荐」一键设置；出征前未备战会提醒，可一键推荐并出征
4. 布阵：发动将令选点时战斗暂停；守城去掉磁石（经验自动吸取）
5. 优化：加载完成自动进入游戏、画面更清晰、长时间战斗更流畅、列表滑动不再拉出空白

更新提醒词库标签：推出新玩法、推出新功能、优化游戏体验

## 三、版本更新信息（15 字以内）
- `天机签上线，摇签定天命`（11 字）
- `新模式天机签，十分钟生存`（12 字）

## 四、广告与 We分析
- 新的激励视频点位共用现有广告位 `adunit-58a7793eb5931638`，`ad_reward` 的 `placement` 新增取值：
  `battle_speed`（守城 / 无尽 / 每周挑战开 1.5 倍速，原 `battle_speed_2x` 停用）、`tianji_draw`（天机签金币不够时看视频抽签）。布阵的 `tower_speed` 仍在（现在是 1.5 倍）。
- `battle_start` / `battle_end` 的 `mode` 新增取值 `tianji`（天机签）。
- 微信好友排行榜新增 `tianji` 榜（开放数据域 key `tianji`，分数为最佳天命伤害）。
