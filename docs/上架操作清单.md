# 上架操作清单（需要你在平台后台完成）

代码已经全部写好。下面这些需要用你的账号在微信、抖音后台操作，填好配置后运行 `npm run build` 重新打包即可。

所有配置都集中在 **`src/data/platformConfig.ts`**。

---

## 一、资质与基础信息（两个平台都要）

- [ ] 注册小游戏账号（企业或个体工商户主体），拿到 **AppID**
- [ ] 计算机软件著作权登记证书（软著）
- [ ] 小游戏 ICP 备案
- [ ] 游戏自审自查报告（平台提供模板）
- [ ] 填写 `GAME_INFO.copyright`（著作权人）和 `GAME_INFO.icp`（备案号），会显示在设置页
- [ ] 用开发者工具导入 `dist/wechat` 或 `dist/douyin`，把 AppID 换成你自己的

本游戏只有广告变现、没有内购，一般不需要版号，具体以平台审核口径为准。

## 二、广告（流量主）

- [ ] 微信：小游戏后台 → 流量主 → 开通，创建「激励视频」「插屏」各一个广告位
- [ ] 抖音：开发者后台 → 运营 → 广告变现，同样创建两个广告位
- [ ] 把广告位 ID 填进 `AD_CONFIG.wx` / `AD_CONFIG.tt`

**注意**：没填广告位时，看视频会直接发奖励（方便你自测）。正式上线前一定要填好。

## 三、云存档

玩家清缓存、换手机后可以自动恢复进度。不开通也能正常玩，只是进度只存在本机。

**微信**
- [ ] 微信开发者工具 → 顶部「云开发」→ 开通，记下**环境 ID**
- [ ] 填进 `CLOUD_CONFIG.wx.env`
- [ ] 云开发控制台 → 数据库 → 新建集合 `saves` 和 `reminders`，权限都选「**仅创建者可读写**」

**抖音**
- [ ] 抖音开发者后台 → 云开发（抖音云）→ 开通，记下环境 ID，填进 `CLOUD_CONFIG.tt.env`
- [ ] 新建集合 `saves`，权限设为仅创建者可读写
- [ ] 抖音云的接口命名和微信略有不同，代码按 `tt.createCloud({ envID }).database()` 编写。请在抖音开发者工具里实际验证一次：设置页会显示「云存档：已同步」，如果显示「同步失败」，把开发者工具控制台的报错发给我

## 四、体力回满 / 巡营满仓提醒（订阅消息，微信）

- [ ] 微信公众平台 → 功能 → 订阅消息 → 选用两个**一次性订阅**模板（例如「游戏通知」类），记下模板 ID
- [ ] 填进 `SUBSCRIBE_CONFIG.wx.stamina` 和 `SUBSCRIBE_CONFIG.wx.patrol`
- [ ] 打开 `platform/wechat/cloudfunctions/notify/index.js`，把 `buildData` 里的字段名（`thing1`、`time3` 等）改成你所选模板的实际字段名
- [ ] 微信开发者工具中：右键 `cloudfunctions/notify` →「上传并部署：云端安装依赖」，再右键 →「上传触发器」（每 10 分钟检查一次到期提醒）

玩家在「设置 → 体力满提醒」里点同意后，消耗体力或领取巡营时会登记一次提醒。微信的一次性订阅每次同意只能发一条，所以玩家需要隔段时间再点一次。

抖音的订阅消息需要自建服务端推送，第一版建议先不开（不填模板 ID 即可，按钮点了会提示未开启）。

## 五、数据埋点

在平台后台新建以下**自定义事件**（名称和字段都要一致），不建的话上报会被平台丢弃，但不影响游戏运行。

- 微信：We 分析 → 自定义分析 → 事件管理 → 新建事件
- 抖音：开发者后台 → 数据分析 → 自定义事件

| 事件名 | 字段 | 说明 |
|---|---|---|
| `battle_start` | mode, chapter, diff, hero | 开始一局（mode：chapter / endless / weekly） |
| `battle_end` | mode, chapter, diff, hero, win, sec, kills, level | 一局结束 |
| `ad_reward` | placement, ok | 每次激励视频（点位、是否看完） |
| `guide_step` | step | 新手引导每推进一步 |
| `hero_unlock` | hero, way | 获得武将 |
| `chest_open` | chest | 开宝箱 |
| `weekly_start` | id | 开始每周挑战 |
| `video_share` | mode | 抖音分享战斗视频 |

上线后最值得看的三个数据：
1. `guide_step` 的漏斗：新手在哪一步流失
2. `battle_end` 中各章节的 win 比例：哪一章卡人
3. `ad_reward` 各点位的次数：哪个广告点位最受欢迎

## 六、抖音录屏分享

- 无需后台配置。战斗开始自动录制，放大招、敌将出场、神兵进化时自动打点剪辑成集锦，结算页出现「分享战斗视频」按钮（每天首次分享奖励 30 元宝）
- [ ] 需要在**真机**上测试（开发者工具不一定支持录屏）

## 八、分享图与隐私

- [ ] 准备一张 5:4 的分享图放到 `platform/wechat/`，填写 `SHARE_CONFIG.imageUrl`
- [ ] 微信后台「用户隐私保护指引」：声明使用了「微信朋友关系」（好友排行榜）
- [ ] 用户协议和隐私政策正文在 `src/data/texts.ts`，按你的运营主体修改「运营方」等信息

## 九、真机验收建议

- [ ] 首次进入：隐私弹窗 → 教学战斗 → 结算 → 主城引导完整走一遍
- [ ] 看一次激励视频，确认奖励到账（填了广告位之后）
- [ ] 切到后台再回来：战斗自动暂停，音乐恢复
- [ ] 设置页显示「云存档：已同步」；删掉小游戏后重新打开，进度能恢复
- [ ] 排行榜能看到好友（需要至少一位好友也玩过）
- [ ] 抖音：从侧边栏进入领取奖励；结算页分享战斗视频
