# 微信「提交审核」——游戏介绍 / 创意说明

## 游戏介绍（90 字，上限 100）
《长坂单骑传》是一款三国题材的像素割草小游戏。你将扮演赵云单骑冲阵，在长坂坡万军之中七进七出，单手就能操作。每局升级三选一、武器进化、锦囊妙计，流派千变万化，五位名将各有专属大招。

## 创意说明（234 字，上限 300）
1.玩法：把割草类玩法和长坂坡故事结合，单手摇杆操控赵云在万军中冲杀，攻击自动释放，玩家专注走位和选择。
2.原创锦囊妙计：每局2:00、5:00、7:30从三条计策中选一条，共24条，分良策、妙计、神机三档，如草船借箭、火烧连营、八阵图，同一武将每局打法都不同。
3.武将专属：赵云、关羽、张飞、诸葛亮、吕布各有大招和专属进化路线。
4.美术与音效：像素美术全部用代码字符画绘制，音效和配乐由程序实时合成。
5.动态难度：按玩家表现调整敌兵强度，新手首局有分步引导。
