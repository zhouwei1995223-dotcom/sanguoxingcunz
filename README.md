# 一骑当千：三国幸存者

类吸血鬼幸存者（Vampire Survivors / 弹壳特攻队）的三国题材竖屏小游戏，可同时发布到**微信小游戏**与**抖音小游戏**。共 5 名武将：赵云、关羽、张飞、诸葛亮、吕布。

- 像素风美术、音效、背景音乐全部由代码生成，没有外部素材版权问题
- TypeScript + 自研轻量 Canvas 引擎，一套代码输出三个平台，包体约 1.3MB（主包限制 4MB）
- 变现方式：激励视频 + 插屏（IAA），没有内购

---

## 一、快速验收（浏览器试玩）

```bash
npm install
npm run build          # 输出 dist/web、dist/wechat、dist/douyin
npx http-server dist/web -p 8080
```

用手机或电脑浏览器打开 `http://<本机IP>:8080`。桌面浏览器可以用鼠标拖动，或用 WASD / 方向键移动。

浏览器调试参数（只在浏览器生效，小游戏里无效），可以组合使用：

| 参数 | 作用 |
|---|---|
| `?reset=1` | 清空存档，从新手开始 |
| `?skip=1` | 跳过隐私弹窗和新手引导 |
| `?rich=1` | 金币、元宝、玄铁、体力充足，方便验收养成系统 |
| `?ch=11` | 解锁全部 10 章（普通难度）和无尽模式 |
| `?speed=4` | 战斗 4 倍速，方便快速验收首领战和结算 |
| `?heroes=1` | 解锁全部武将 |
| `?cloud=1` | 用本地模拟云存档（测试同步与恢复） |

示例：`http://localhost:8080/?skip=1&rich=1&ch=5&speed=3`

浏览器里的广告是模拟弹窗（倒计时 2 秒自动发奖励，也可以点「关闭」测试不发奖励的情况）。

## 二、导入开发者工具

| 平台 | 目录 | 操作 |
|---|---|---|
| 微信 | `dist/wechat` | 微信开发者工具 → 导入项目 → 选择该目录 → 填入你的小游戏 AppID |
| 抖音 | `dist/douyin` | 抖音开发者工具 → 导入项目 → 选择该目录 → 填入你的小游戏 AppID |

`project.config.json` 里默认是测试 AppID（`touristappid` / `testappid`），导入时替换成你自己的即可。

## 三、上架前需要你填写的配置

> 完整的后台操作清单（广告、云开发、订阅消息、埋点事件、资质）见 **[docs/上架操作清单.md](docs/上架操作清单.md)**。


都在 `src/data/platformConfig.ts` 里，改完重新执行 `npm run build`：

1. **广告位 ID**：`AD_CONFIG.wx` / `AD_CONFIG.tt` 的 `rewarded`（激励视频）和 `interstitial`（插屏）
   - 微信：小游戏后台 → 流量主 → 广告管理
   - 抖音：开发者后台 → 运营 → 流量主 / 广告变现
   - 没填广告位时，激励视频会直接发奖励（`grantWhenNoAd: true`），方便提审前自测；正式上线请务必填好
2. **著作权人 / 备案号**：`GAME_INFO.copyright`、`GAME_INFO.icp`，会显示在「设置」页底部
3. **分享图**（可选）：`SHARE_CONFIG.imageUrl`，放一张 5:4 的图片到 `platform/wechat/` 并填写文件名
4. 用户协议 / 隐私政策正文在 `src/data/texts.ts`，可按你的运营主体修改

## 四、上架资质清单（参考，以平台最新要求为准）

- 计算机软件著作权登记证书（软著）
- 小程序 / 小游戏 ICP 备案
- 游戏自审自查报告（平台提供模板）
- 适龄提示：游戏内已显示 8+（启动页和设置页），需要的话可以在 `GAME_INFO.ageRating` 修改
- 健康游戏忠告：启动页已展示
- 只走广告变现、没有内购的游戏一般不需要版号，但具体以平台审核口径为准
- 抖音：已接入「侧边栏复访」奖励（审核常查项）、添加到桌面
- 微信：后台「用户隐私保护指引」里需要声明好友排行榜用到的「微信朋友关系」（开放数据域 `getFriendCloudStorage`），否则排行榜可能拿不到数据
- 微信、抖音的实名认证和防沉迷由平台统一处理，游戏内不用额外接入

## 五、游戏内容

### 武将

| 武将 | 定位 | 专属武器（进化） | 大招 | 天赋 | 获取 |
|---|---|---|---|---|---|
| 赵云 | 均衡突进 | 龙胆枪（百鸟朝凤） | 龙胆·七进七出 | 低血量伤害+30% | 初始 |
| 关羽 | 重击近战 | 青龙偃月刀（春秋刀法） | 青龙出水 | 暴击率+8%、暴伤+60% | 第2章首通 / 50碎片 |
| 张飞 | 坦克控场 | 丈八蛇矛（万人敌） | 据水断桥（全屏眩晕） | 减伤15%，受伤攒怒气 | 七日签到第7天 / 50碎片 |
| 诸葛亮 | 远程法术 | 羽扇（八阵图） | 借东风（火焰龙卷） | 冷却-15%、范围+15% | 50碎片 |
| 吕布 | 无双猛将 | 方天画戟（无双乱舞） | 天下无双（5秒无敌旋风） | 伤害+20%、移速+8% | 100碎片 |

- 每名武将独立等级（金币升级）与星级（1～5 星，碎片升星，每星基础攻击生命 +12%）
- 碎片来源：军资箱（40% 概率）、名将宝匣（必出，偏向吕布）、商店每日看视频、活跃度宝箱、第3章起首通奖励；已拥有的武将再次获得会转为 20 碎片
- 专属武器只有对应武将能用，其余 11 种通用武器所有武将共用
- **专属联动**：每名武将和 1～2 种通用武器有联动，用该武将进化这把武器时变成专属形态（武将页和局内进化表可查）

  | 武将 | 联动武器 → 专属形态 |
  |---|---|
  | 赵云 | 青锋剑 → 青釭剑阵；轻骑 → 白马义从 |
  | 关羽 | 战鼓 → 温酒斩华雄（鼓响时四向刀气）；轻骑 → 千里走单骑（移速+20%） |
  | 张飞 | 战鼓 → 长坂断喝（大范围长眩晕）；滚木礌石 → 智取瓦口 |
  | 诸葛亮 | 连弩 → 元戎弩（十矢扇射）；火油罐 → 火烧博望 |
  | 吕布 | 连弩 → 辕门射戟（贯穿巨箭）；霹雳车 → 虎牢关 |

### 局内（战斗）
- 单指浮动摇杆移动，自动攻击，每局 10 分钟，第 5 分钟和第 10 分钟各有一名敌将
- **16 种武器**（每名武将可用 12 种：11 通用 + 1 专属），各 5 级，满级后搭配对应兵法、开宝箱可以**进化**：

  | 武器 | 进化形态 | 所需兵法 | 出现条件 |
  |---|---|---|---|
  | 青锋剑 | 万剑归宗 | 令旗 | 初始 |
  | 连弩 | 诸葛连弩 | 兵书 | 初始 |
  | 轻骑 | 铁骑突阵 | 战马 | 初始 |
  | 火油罐 | 火烧连营 | 锦囊 | 初始 |
  | 罡风 | 金刚护体 | 灵芝 | 初始 |
  | 回旋飞刀 | 飞刀如雨 | 美酒 | 通关第1章 |
  | 天雷 | 太平要术 | 玉玺 | 通关第1章 |
  | 滚木礌石 | 天崩地裂 | 铁甲 | 通关第2章 |
  | 战鼓 | 擂鼓震天 | 号角 | 通关第2章 |
  | 霹雳车 | 霹雳炮 | 磨刀石 | 通关第3章 |
  | 铁蒺藜 | 天罗地网 | 锦囊 | 通关第3章 |

- **15 种兵法（被动）**：战马、铁甲、兵书、令旗、虎符、灵芝、锦囊、聚宝盆、玉玺；通关第1章加入美酒；第2章加入号角、磨刀石；第3章加入舆图（技能数量+1，最高2级）、护心镜、军粮
- **选技能**：卡片上直接显示进化配方；能凑齐进化的标「可进化」，专属联动标「★专属」，每次有一项标「推荐」（照着推荐点也能玩得很爽）；每局可**封禁** 2 个不想要的新技能；暂停界面有**进化表**
- **刷怪**：补怪速度跟随击杀速度；4 分钟后敌人逐渐增多（10 分钟时约为原来 1.6 倍，血量也更高，经验按人数摊薄）；敌人总是还没靠近就被消灭时，新敌人血量会逐步提高（最多 2 倍，场面饱满后回落）；四成敌人刷在前进方向；第 4.5、8.5 分钟各有一次「敌军大举压境」；手机持续掉帧时自动减少同屏敌人
- **大招「龙胆·七进七出」**：击杀积攒怒气，满了以后点右下角按钮，慢动作中化身白龙连冲 7 次，最后全屏冲击波；每局可看视频充满怒气 2 次（电脑上也可以按空格键释放）
- **打击感**：重击顿帧、敌人被击飞旋转、多人贯穿时震屏、火油罐落地爆炸、连斩计数（百人斩等）
- **拾取**：磁石会从精英怪必掉、小兵小概率掉，场上没有磁石时约每 60～85 秒保底刷一个；屏幕外的磁石、宝箱、包子在屏幕边缘有箭头提示；宝石放置 9 秒后会自动飞向赵云
- 升级三选一（可刷新：军略「奇谋」次数 + 看视频刷新）
- 精英怪、首领掉宝箱（随机 1/3/5 项升级，优先进化）
- 事件：流寇来袭、四面伏兵（包围圈）、骑兵冲阵、十面埋伏
- 可破坏的灯笼、粮车，掉落肉包子（回血）、磁石（吸取全部经验）、震天雷（清屏）、金币
- 首领技能会预警：冲锋、旋风斩、投掷扇形弹幕、跳斩、召唤、环形箭雨
- 复活：军略「不屈」免费复活，或看视频复活（每局 1 次）
- 结算：金币、玄铁、元宝、装备掉落，看视频双倍领取

### 局外（养成与运营）
- **10 个章节**：长坂坡、取桂阳、汉水之战、凤鸣山、箕谷断后、虎牢关、官渡、赤壁、夷陵、五丈原，各有不同地貌和敌军（曹军、袁军、吴军、西凉军等），共 20 名敌将
- **3 档难度**：普通 / 困难（敌军生命×2.4）/ 噩梦（×5.5），通关某章的上一难度后解锁该章下一难度；奖励更高、装备品质更好，首通额外送吕布碎片
- **无尽模式**：通关第 3 章解锁；没有时间上限，敌人强度随时间加速成长，每 3 分钟一名敌将，强度随玩家章节进度调整；每坚持 5 分钟额外奖励碎片和元宝；独立排行榜
- **章节总览**：一屏查看全部章节在三个难度下的通关情况，点击直接选关
- **武将升级**（金币）
- **装备**：6 个部位、12 件名品、6 档品质（普通 → 神话）；可强化（金币 + 玄铁），3 件合成升品，品质越高解锁的特效越多；支持一键穿戴、一键合成
- **军略（天赋）**：12 项永久属性，随章节进度解锁
- **商店**：军资箱 / 名将宝匣（看视频免费或花元宝开，名将宝匣 10 抽保底史诗），每日礼包，看视频领元宝、金币，元宝换玄铁
- **体力**：每局消耗 5 点，每 5 分钟恢复 1 点，可以看视频或花元宝补充
- **巡营（离线挂机收益）**：最多累计 12 小时，可看视频双倍领取，每日 3 次「快速巡营」
- **七日签到**（可看视频双倍）、**每日任务 + 活跃度宝箱**
- **排行榜**：微信好友排行（开放数据域）、抖音排行榜
- **新手引导**：首次进入直接开始教学战斗，回到主城后引导装备、军略、出征
- **新手七日目标**：前 7 天每天 3 个目标（共 21 个），完成 7 / 14 / 21 个分别领取元宝、吕布碎片、武将诸葛亮；开放 14 天
- **成就**：击杀、斩将、通关、困难与噩梦、无尽、武将收集、升星、连斩、大招、进化、宝箱、神话装备、图鉴等 40 余项分档成就
- **图鉴**：敌将、兵种、神兵（进化形态）三类，首次点亮奖励元宝，一键领取
- **每周挑战**：每周一轮换一种特殊规则（骑兵狂潮、玻璃大炮、车轮大战、火烧连营、风驰电掣），坚守 8 分钟比击杀数，三档奖励
- **武将皮肤**：每名武将一款皮肤（换坐骑和配色，伤害 +5%），看视频累计解锁
- **装备套装**：龙胆套装、虎威套装，2 / 4 / 6 件生效
- **兑换码**：设置页输入，码表在 `platformConfig.ts` 中维护
- **云存档**：微信云开发 / 抖音云，启动时自动恢复、运行中每分钟同步、切后台时同步
- **订阅提醒**：体力回满、巡营满仓（微信，需部署 `cloudfunctions/notify` 云函数）
- **抖音录屏**：整局录制，精彩时刻自动剪辑成集锦，结算页一键分享
- **数据埋点**：开局、结算、广告、新手引导、武将获取、宝箱等事件
- **设置**：音乐、音效、震动、伤害数字开关；兑换码、提醒订阅、云存档状态；用户协议、隐私政策、健康游戏忠告
- **合规**：启动页健康游戏忠告与适龄提示，首次进入的隐私协议确认

## 八、数值调整

所有数值都集中在 `src/data/`：

- `skills.ts`：武器每级伤害、冷却、数量，被动效果，升级经验曲线
- `enemies.ts`：小兵和首领的血量、速度、伤害、技能
- `chapters.ts`：每章的刷怪时间轴、密度、事件、血量倍率、推荐战力
- `meta.ts`：武将成长、装备、军略、体力、巡营、宝箱概率、签到、每日任务、商店

调整后可以用 `npm run sim` 快速验证难度。参考结果（自动走位机器人，会放大招）：初始属性稳定通关第 1 章；攻击 70 / 生命 450 稳定通关第 2 章；攻击 120 / 生命 800 稳定通关第 3 章；攻击 200 / 生命 1400 约 2/3 通关第 4 章。
